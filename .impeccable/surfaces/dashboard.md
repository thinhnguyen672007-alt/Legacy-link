# Dashboard direction contract

Mode: Operate. Code-first. User confirmed React + TypeScript, light, concise,
readable; delegated remaining implementation choices. No approved image comp.
Seed: 04d90571. User-pinned practical light dashboard takes precedence over the
seed's stylistic challengers; the assigned candidate slot is interpreted within
that brief as a maintenance reference sheet's readable measurements and columns.

## THESIS

A factory team can inspect which gateway is reporting, read its measurements,
and trace those measurements to the machine register map.

## OWN-WORLD

Light cool-gray workspace, white working surfaces, restrained cobalt actions,
Manrope UI, IBM Plex Mono identifiers, fine neutral table rules. Reference-sheet
precision appears in the side-by-side raw/Modicon/type/scale/value columns.
Standard web navigation and controls remain familiar. No imagery is necessary.

## STORY

Connect the team's backend; scan the fleet; select one machine; inspect its
latest stored values; trace a value to the read-only catalog. Configuration
publishing, historical charts and alarm history are explicitly pending APIs.

## FIRST VIEWPORT

Persistent navigation, page title and live/sample source controls, connection
feedback, compact fleet summary and searchable machine table. Selected readings
follow the fleet. On mobile, top navigation and stacked measurements replace
the sidebar and measurement columns. Critical gateway states must remain legible.

## FORM

An operations workspace with three hash routes: overview, registers, connection.
One status vocabulary covers online, offline, no recent contact, awaiting data,
clock mismatch and unverified snapshots. Sample mode is opt-in and labeled.

## QUALITY BAR

Working controls, complete loading/error/empty states, honest data semantics,
keyboard and screen-reader support, no document overflow at 359/390/768/1440px,
self-hosted fonts, clear connection recovery, and readable source code.
